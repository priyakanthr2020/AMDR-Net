# AMDR-Net: Adaptive Multi-Degradation Restoration Network for Semiconductor Inspection

## Overview

AMDR-Net is a deep learning-based image restoration framework designed for semiconductor inspection applications. The network is developed to restore high-resolution semiconductor inspection images from degraded low-resolution and noisy inputs.

The proposed framework combines degradation analysis, adaptive feature fusion, spatial-domain processing, frequency-domain feature extraction, multi-scale feature fusion, residual dense reconstruction, and CBAM-based attention to improve the quality of restored semiconductor inspection images.

The repository provides the trained model, training notebook, standalone evaluation script, requirements, and restored test outputs to support reproducibility and evaluation.

---

## Problem Statement

Semiconductor inspection systems can produce degraded images because of factors such as:

- Sensor noise
- Resolution limitations
- Imaging degradation
- Loss of high-frequency information
- Manufacturing-environment variations

These degradations can affect the visibility of fine structures and defects in semiconductor inspection images.

AMDR-Net addresses this problem by learning to restore high-resolution images from degraded low-resolution inputs while preserving important spatial and frequency-domain information.

---

## Proposed Solution

AMDR-Net uses an adaptive restoration architecture consisting of the following major components:

1. Degradation Analysis Module (DAM)
2. Adaptive Feature Fusion Controller
3. Adaptive Feature Fusion
4. Dual-Branch Feature Extraction
5. Spatial Feature Branch
6. Frequency Feature Branch
7. Multi-Scale Feature Fusion
8. Residual Dense Reconstruction
9. CBAM Attention
10. Pixel-Shuffle Based Upsampling
11. Final Image Reconstruction

The network uses degradation information extracted from the input image to adaptively control feature processing.

Spatial-domain features capture structural information, while frequency-domain processing helps preserve high-frequency information that is important for semiconductor inspection.

Installation

Clone the repository:

git clone https://github.com/priyakanthr2020/AMDR-Net.git
cd AMDR-Net

Install the required Python packages:

pip install -r requirements.txt

A CUDA-enabled PyTorch installation is recommended when GPU inference is required.

Trained Model

The trained AMDR-Net weights are provided in:

AMDRNet_Final.pth

The model checkpoint is loaded directly during standalone evaluation.

Running Inference

The standalone evaluation script is available at:

evaluation/evaluate.py

Run the model using:

**python evaluation/evaluate.py \
    --input_dir <path_to_input_directory> \
    --output_dir <path_to_output_directory> \
    --model AMDRNet_Final.pth**
Example
python evaluation/evaluate.py \
    --input_dir ./data/Test_NoisyLR \
    --output_dir ./results/restored_outputs \
    --model ./AMDRNet_Final.pth

The script automatically:

Loads the trained AMDR-Net model.
Reads .npy input images.
Normalizes the input values.
Performs restoration.
Clips the restored output to [0,1].
Saves the restored images as .npy files.
Reports inference time and throughput.
Evaluation Script

The standalone evaluation script performs inference on all .npy files present in the specified input directory.

The script reports:

Number of input images
Number of processed images
Total inference time
Average inference time per image
Throughput in images/second

The script is designed to allow independent evaluation without requiring the original training notebook.

GPU hardware
CUDA version

Disk I/O performance
