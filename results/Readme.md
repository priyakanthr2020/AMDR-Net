This folder contains the restored outputs generated by the final AMDR-Net model on the complete test dataset.

- Number of test images: 400
- Input format: `.npy`
- Input resolution: 128 × 128
- Output resolution: 256 × 256
- Output datatype: `float32`
- Output value range: [0, 1]
